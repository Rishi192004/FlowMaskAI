1. EXECUTIVE SUMMARY & PROJECT PURPOSE
--------------------------------------------------------------------------------
FlowMind is an enterprise-grade Process Mining and Operational Analytics Platform.
Its core mission is to ingest raw enterprise event logs (specifically Purchase-to-Pay / P2P),
reconstruct actual as-executed business workflows, quantify operational bottlenecks,
detect process deviations and compliance breaches against a reference standard, and 
provide evidence-based recommendations grounded strictly in computed metrics.

Target P2P Reference Flow:
  [Purchase Requisition] ──> [Manager Approval] ──> [Purchase Order Created]
       ──> [Goods Received] ──> [Invoice Received] ──> [Invoice Verified]
       ──> [Payment Completed]

2. CHRONOLOGICAL TIMELINE OF WHAT HAS BEEN DONE
--------------------------------------------------------------------------------
The project was executed in sequential phases based on a rigorous master plan:

• Phase 0 — Product Planning & Architecture (Commit: e8767cc)
  - Authored a comprehensive Product Requirements Document (PRD) and Master Plan
    (stored in FlowMind_Planning.md).
  - Defined system architecture, PostgreSQL database schemas, PM4Py integration flow,
    REST API specifications, frontend React component design, and acceptance criteria.

• Phase 1 — Scaffolding & Backend Foundation (Commit: e8767cc)
  - Established modular backend structure: app/api, core, db, models, schemas, services.
  - Implemented FastAPI app factory, CORS middleware, structured JSON logging,
    custom exceptions, and JWT authentication (login, register, token refresh).
  - Configured PostgreSQL engine with SQLAlchemy 2.0 and Alembic migrations.
  - Set up Dockerfile and docker-compose.yml for postgres, backend, and frontend.

• Phase 2 & 3 — ETL & Event-Log Processing Pipeline (Commit: 65c65d3)
  - Created Alembic migration (0002) for datasets and events tables.
  - Built streaming ETL engine:
    * File format & delimiter detector (app/etl/detector.py).
    * Column mapping & data validator (app/etl/validator.py).
    * Data normalizer & timestamp sanitizer (app/etl/normalizer.py).
    * Robust chunked database loading pipeline (app/etl/pipeline.py).
  - Synthesized a realistic 100,000-event P2P sample dataset (data/sample/p2p_100k_events.csv)
    with intentional real-world anomalies, delays, rework, and deviations.

• Phase 4 — Operational Analytics Engine (Commit: 65c65d3)
  - Built SQL query aggregation and Pandas analytical service (app/analytics/):
    * Case throughput (total, completed, open/in-progress).
    * Cycle time percentiles (min, max, mean, median, P50, P75, P90, P95, histogram bins).
    * Stage-by-stage waiting time and processing duration rankings (bottlenecks).
    * Rework rates and activity repetition frequency.
    * SLA compliance tracking and SLA breach rates.
    * Vendor performance analytics (spend volume, breach rate, avg duration).
  - Exposed full analytics suite via FastAPI endpoints at /api/v1/analytics/*.

• Phase 5 — Process Mining Engine via PM4Py (Commit: 6c77bbf)
  - Integrated PM4Py 2.7+ for actual algorithmic workflow discovery:
    * Converter: Transforms DB records into PM4Py EventLogs and Pandas DataFrames.
    * Discovery: Generates Directly-Follows Graphs (DFG), transition frequencies,
      average transition durations, and Inductive Miner Petri nets.
    * Variant Explorer: Extracts trace variants, computes variant frequency distributions,
      and performs Pareto coverage analysis.
    * Process Comparison: Enables differential workflow comparisons across departments,
      vendors, or time windows.
  - Exposed process mining endpoints at /api/v1/process/*.

• Phase 6 — Conformance Checking & Deviation Detection (Commit: 6d6301f)
  - Formulated formal business rules for the P2P reference process (app/conformance/rules.py).
  - Built token replay and trace alignment heuristic engine (app/conformance/engine.py):
    * Detects Skipped Manager Approvals (unauthorized procurement).
    * Detects Maverick Buying (Goods Received before PO Created).
    * Detects Early Invoicing (Invoice Received before Goods Received).
    * Detects Skipped Invoice Verification (Payment without 3-way match).
    * Detects Rework loops, repeated approvals, and abandoned cases.
    * Classifies deviation severity (LOW, MEDIUM, HIGH) with financial impact.
  - Exposed conformance endpoints at /api/v1/conformance/*.

• Phase 7 — React Frontend & Dashboard (Commit: 6d6301f - Partial)
  - Scaffolding of React 18 + TypeScript + Vite + Tailwind CSS dashboard.
  - Configured dark navy/slate enterprise UI theme and FilterContext for global filtering.
  - Developed full Axios API layer for all backend modules.
  - Implemented interactive ProcessMapCanvas using React Flow.
  - Built 8 dashboard pages:
    1. OverviewDashboard.tsx (KPI summary cards, volume trend charts, cycle time histogram)
    2. DatasetManagement.tsx (Dataset list, metadata display, upload dropzone)
    3. ETLProcessing.tsx (Column mapping confirmation, ingestion logs, status badges)
    4. DataQualityReport.tsx (Data health metrics, null/invalid counts, anomaly summary)
    5. ProcessDiscovery.tsx (Interactive React Flow diagram, node detail inspector)
    6. VariantExplorer.tsx (Trace variant tables, step sequence visualizer, case counts)
    7. ConformanceChecking.tsx (Fitness score meter, deviation breakdown, audit log)
    8. BottleneckAnalysis.tsx (Activity wait time rankings, stage duration percentiles)

3. CURRENT PROJECT ARCHITECTURE & TECH STACK
--------------------------------------------------------------------------------
Backend:
  • Python 3.11+, FastAPI (REST API Gateway)
  • SQLAlchemy 2.0 (ORM) + Alembic (Schema Migrations)
  • PostgreSQL 16 (Relational & JSONB Storage)
  • PM4Py 2.7+ (Process Mining discovery, DFG, trace variants, token replay)
  • Pandas 2.0+ & NumPy (Data manipulation & percentiles computation)
  • Pydantic v2 (Input validation & schema serialization)
  • Python-Jose & Passlib (JWT authentication & Bcrypt password hashing)

Frontend:
  • React 18 + TypeScript + Vite
  • Tailwind CSS (Enterprise slate/navy theme)
  • React Flow (Interactive directed process graph visualization)
  • Recharts (Metric cards, histograms, and trend analytics)
  • Lucide React (Iconography)

Testing & Infrastructure:
  • Pytest, pytest-cov, FastAPI TestClient
  • Docker, Docker Compose (Multi-container orchestration)
